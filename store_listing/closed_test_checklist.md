## 4. アプリの権限（審査で説明を求められやすい箇所）

Manifest で宣言している権限と用途:
- `USE_BIOMETRIC` … 起動ロックの生体認証
- `WRITE_EXTERNAL_STORAGE`（maxSdk 28 想定）… 旧端末での書き出し保存
- `READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO` は **削除済み**（`tools:node="remove"`）。写真添付は Photo Picker 経由なので許可不要
- `INTERNET` … 広告表示（AdMob）
- INTENT: `SEND` / `SEND_MULTIPLE` 受信 … LINE の「テキストで送信」共有を受け取るため

- [ ] 機密性の高い権限（バックグラウンド位置情報・SMS・通話履歴など）は **未使用** を確認
- [ ] `QUERY_ALL_PACKAGES` は未使用（`<queries>` で mailto など限定宣言のみ）
